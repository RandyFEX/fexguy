- Section: Best practices for influencing title links
- Classification: RECOMMENDED
- Passage: "Avoid repeated or boilerplate text in <title> elements. It's important to have distinct text that describes the content of the page in the <title> element for each page on your site. Long text in the <title> element that varies by only a single piece of information ("boilerplate" titles) is also bad; for example, a common <title> element for all pages with text like "Band Name - See videos, lyrics, posters, albums, reviews and concerts" contains a lot of uninformative text. One solution is to dynamically update the <title> element to better reflect the actual content of the page. For example, include the words "video" and "lyrics" only if that particular page contains video or lyrics."
